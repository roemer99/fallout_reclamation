# FALLOUT RECLAMATION - Vault buildings
# =============================================================================
# Vault buildings take their maintenance goods from the Vault's own market, which
# is stocked with 200 years of supplies at game start
# (scripted_effects/fallout_vault_storage_effects.txt).

# script_values/fallout_vault_resource_values.txt
# =============================================================================
