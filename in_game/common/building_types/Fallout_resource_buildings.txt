# =============================================================================
# FALLOUT RECLAMATION - Resource buildings (RGO)
# =============================================================================
# The only vanilla buildings kept in the mod: every building with
# category = rgo_building_category, copied from vanilla 1.4
# (common_buildings.txt and rural_buildings.txt).

# Sealed Vaults (Isolationism) cannot build any of them (country_potential).
# =============================================================================
